## 四层机制

**检索排序**（`src/l1-decay.ts`，原样进 MemoryCore 的那份）。命中分数乘一个 `[0.3, 1.5]` 的系数：

```
decay = 0.3 + 0.7 × 2^(−age / 30d)
usage = 1 − exp(−access_count / 5)
multiplier = clamp(decay + 0.5 × usage, 0.3, 1.5)
```

地板 0.3 保证候选不消失，只降序。公式借 MemOS，取值借 mem0。

**pin 豁免**（`src/pin.ts`）。两级：`priority = −1`、`metadata.pin`、指令型记忆断言"永久"→ hard，系数恒 1.0、不衰减不淘汰；非指令型记录**引用**"永久记住"→ extended，半衰期 ×12。区分依据是语料：一条 episodic 里写着"用户要求 AI 永久记住 X"，那是请求的记录，不是请求本身。

**淘汰计划**（`src/planner.ts` + `src/applier.ts`）。顺序 pin → 绝对阈值 → 冗余 → 配额。冗余用 4-gram shingle + Jaccard 单链接（阈值 0.6），不依赖 embedding 服务。落库全程一个事务，写 `forgetting_audit` 与 `forgetting_runs`，软删除，回滚是一条 UPDATE。

**访问证据**（`src/recall.ts`）。`appendRecall` 在检索路径追加 JSON 行（fire-and-forget），`foldAccessLog` 离线聚合成计数器并把日志重命名归档——不是截断，因为进程可能死在重命名与提交之间。

## 三条实测结论

语料：822 条真实 L1（519 条带 bge-m3 向量），ground truth 用 embedding 余弦独立构建，不与被测的两条检索路径共享机制。

**冷启动时衰减有害。** 访问覆盖率 0% 时强制开启，precision@10 从 0.955 掉到 0.920。默认加 10% 覆盖门槛，低于它年龄项整体退出。这不是保守，是把没证据的前提关掉。

**pin 提到上限有害。** 初版给 1.5，想着"永不遗忘就该排前面"，实测 0.920 → 0.885；从候选池移除更糟，0.780。最终 1.0。永不遗忘是关于保留的承诺，不是关于排序的承诺。

**衰减只改排序，不改取舍。** 受控语料（每事实 90/60/30 天三次复述）：衰减把"最新版排第一"从 0 拉到 1.000，但窗口内过期副本仍是 2 条；显式 `invalid_at` 两件都做到。所以时间衰减是失效标记的代理，字段能表达的东西不该用启发式去猜。

第五条实验（合成语料上的冗余合并）只验证机制能跑通、能进 CI，不构成效果证据——它的 precision 按"同话题"判，不是"答得上"，报告里写明了这一点。

## 两次 CI 失败，两个真教训

首轮 5 个 job 挂 4 个，原因互不相关：

**Node 下限写错了。** `>=22.16.0` 是照着 `node:sqlite` 的引入版本推的，没实测。类型擦除到 22.18 才无标志默认开启，12 个测试文件在 22.16 上全部 `ERR_UNKNOWN_FILE_EXTENSION`，一条断言都没跑。已改 22.18，README 与 CONTRIBUTING 同步。**engines 的下限必须由 CI 证明，不能由推断给出。**

**一个测试用了 Windows 盘符路径。** 原本用盘符形式的路径构造不可写场景，那个字符串在 Linux 上是合法的相对文件名，append 反而成功。改成"父路径是普通文件"的构造，三平台都必然失败。**跨平台测试里不要出现盘符。**

## 还缺什么

按风险排，不是按工作量排：

1. **容器内冒烟未做**。四份补丁已经能应用、能构建、能过类型检查，但没在真实容器里跑过。验证过程中已经挖出一个真缺陷（归档后的记录仍能从 FTS 和向量两条路径召回，详见 [补丁落地验证](../design/补丁落地验证-2026-10-26.md)），说明剩下的未知量不是零。
2. **访问追踪没接进 gateway**。`appendRecall` 目前只有 CLI 与测试在调。不接的话覆盖率永远是 0，门槛永远关着，衰减在真实部署里等于不存在。
3. **过期失效没做**。实验三已经证明它比时间衰减更强，字段（`invalid_at` / `superseded_by`）和 dedup 判据都还没设计。
4. **参数是拍的**。10% 门槛、30 天半衰期、0.6 Jaccard 只在两三份语料上验证过。长文本的 shingle 相似度会被稀释，阈值可能需要按长度分档。
5. **没有调度**。故意只给命令，阈值该先被人工审几轮。
6. **只覆盖 L1**。L0/L2/L3 语义不同，不能套同一个分数。
